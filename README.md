# ЛР1, вариант 11 — как запускать

## Что делает программа

Уточняет поле, полученное линейным МКЭ, сглаживающим кубическим сплайном Эрмита на треугольниках.

Минимизируется:

`F = сумма квадратов ошибок по точкам + α·∫|∇P|² + β·∫(P_xx² + P_yy²)`

## Порядок запуска

1. (Опционально) Посчитать «грубое» поле линейным МКЭ:

```text
python magnetic_main.py
```

Должен появиться файл `two_triangles.msh_poi_values.json` (уже есть в папке).

2. Построить сплайн:

```text
python splain_maker.py
```

Параметры в `parameters.json`:
- `alpha` — штраф на градиент (основной для варианта 11). На грубой сетке `two_triangles` берите порядка `1e-4`…`0.01`. Слишком большой (`1`) сильно «сплющит» поле.
- `beta` — штраф на вторые производные (можно `0`, если хватает `alpha`)
- `mesh_file`, `poi_values_file`, контрольные точки

Рекомендуемый эксперимент: прогнать `alpha = 1e-6`, `0.01`, `1.0` и сравнить картинки / ошибки в `*_splain_results.txt`.

3. Нарисовать уточнённое поле:

```text
python field_drawer.py
```

В `field_parametres.json` указан `values_file` = `*_splain_nodal_values.json`.

## Результаты `splain_maker.py`

| Файл | Содержание |
|---|---|
| `*_splain_values.json` | полный вектор q (значения, ∂/∂x, ∂/∂y в узлах + центры) |
| `*_splain_nodal_values.json` | значения в вершинах — для картинки |
| `*_splain_poi_values.json` | значения и производные в контрольных точках |
| `*_splain_results.txt` | таблица сравнения с эталоном |

## Зависимости

`gmsh`, `numpy`, `matplotlib` (для рисовалки).
