# ЛР1, вариант 11 — как работать с программой

Что делает каждый файл и какие формулы используются — в [ОПИСАНИЕ_ФАЙЛОВ.md](ОПИСАНИЕ_ФАЙЛОВ.md).

## 1. Установка (один раз)

Нужен Python 3.9+.

```text
pip install gmsh numpy matplotlib
```

Все команды ниже выполняются **из папки программы**: скрипты ищут `parameters.json` и остальные файлы в текущей папке.

## 2. Первый запуск после `git clone` / `git pull`

Результаты расчёта (`*_values.json`, `*_results.txt`) в репозиторий не входят, их нужно пересчитать:

```text
python run_all.py mesh0.msh mesh1.msh mesh2.msh
```

Для каждой сетки выполняются три шага (около 5–10 секунд на все три сетки). Последняя сетка в списке остаётся в `parameters.json`. Без пересчёта `splain_maker.py`, `graph_drawer.py` и `field_drawer.py` упадут с ошибкой «файл не найден».

## 3. Цепочка расчёта по шагам

`run_all.py` делает то же самое, что эти три команды подряд. Их удобно запускать по одной, если нужно менять параметры между шагами.

```text
python poi_gen.py mesh1.msh   # 1. точки интереса и эталон U → parameters.json
python magnetic_main.py       # 2. линейный МКЭ → mesh1.msh_values.json, mesh1.msh_poi_values.json
python splain_maker.py        # 3. сплайн Эрмита → mesh1.msh_splain_*.json
```

Порядок важен: каждый шаг читает результат предыдущего. `magnetic_main.py` и `splain_maker.py` в конце ждут Enter, чтобы окно не закрылось при запуске двойным щелчком.

## 4. Просмотр результатов

**Таблицы ошибок:** `<сетка>_results.txt` (МКЭ) и `<сетка>_splain_results.txt` (сплайн). Столбцы: номер, x, y, вычисленное значение, точное \(U\), разность, ошибка в процентах.

**Графики вдоль прямой** (значение и производные для \(U\), МКЭ, сплайна):

```text
python graph_drawer.py
```

Настройки в `graph_parameters.json`:
- `mesh_file` — сетка (для неё уже должен быть выполнен расчёт);
- `func_num` — номер \(U\), тот же, что в `materials.json`;
- `start`, `stop` — концы прямой;
- `n_ints` — число отрезков.

Прямую лучше вести поперёк элементов (по умолчанию \(y = 0.13\)). На рёбрах производные сплайна Эрмита разрывны по построению.

**Карта поля:**

```text
python field_drawer.py
```

В `field_parametres.json` укажите `mesh_file` и `values_file`: `<сетка>_splain_nodal_values.json` для сплайна или `<сетка>_values.json` для МКЭ.

## 5. Как менять условия эксперимента

### Тестовая функция U

Номер задаётся в **двух местах**, и он должен совпадать:
- `materials.json` → `"f_fun"` (правая часть МКЭ, по нему же `poi_gen` считает эталон);
- `mag_edge_conditions.json` → `"u_fun"` у каждой линии (краевые условия).

И ещё в `graph_parameters.json` → `"func_num"` для графиков.

| Номер | U |
|---|---|
| 0 | \(x+y\) |
| 1 | \(x^2+y^2\) |
| 2 | \(x^3+y^3\) |
| 3 | \(x^4+y^4\) |
| 4 | \(\sin x+\sin y\) |

После смены функции перезапустите `run_all.py`.

### Регуляризация сплайна

В `parameters.json`:
- `alpha` — штраф на градиент \(\iint|\nabla P|^2\);
- `beta` — штраф на вторые производные \(\iint(P_{xx}^2+P_{yy}^2)\).

| Значение | Эффект |
|---|---|
| `0, 0` | Сплайн точно следует данным МКЭ (со всеми изломами) |
| `beta` = 0.01–0.1 | Сглаживание изломов МКЭ; ошибка производных заметно падает |
| `alpha` ~ 1 | Пересглаживание: поле «сплющивается» |

После изменения достаточно перезапустить только `python splain_maker.py`: МКЭ пересчитывать не нужно.

### Своя сетка

1. Постройте сетку в `mesh_generator.py` или в Gmsh. Треугольники должны быть в физической группе 2D, граница — в физической группе 1D с номером 1.
2. Добавьте сетку в словарь `DIVISIONS` в `poi_gen.py`. \(N\) подбирается так, чтобы в каждом элементе было не меньше 10 точек (шаг сетки точек \(1/N\)). Если сетки нет в `DIVISIONS`, берутся точки, уже записанные в `parameters.json`.
3. Проверьте `mag_edge_conditions.json`: номера линий должны соответствовать границе новой сетки.

## 6. Частые ошибки

| Симптом | Причина и решение |
|---|---|
| `No such file ... _poi_values.json` / `_values.json` | Не выполнены предыдущие шаги — запустите `python run_all.py <сетка>` |
| В `*_splain_results.txt` огромные ошибки, у элементов «Попаданий» меньше 10 | Мало точек интереса: увеличьте \(N\) в `poi_gen.py` или задайте `alpha`/`beta` > 0 |
| Проценты ошибок не соответствуют графикам | `true_values` посчитаны для другой функции: перезапустите `poi_gen.py` после смены `f_fun` |
| Решение МКЭ не совпадает с \(U\) даже на мелкой сетке | Номера `f_fun` и `u_fun` не совпадают |
| `'charmap' codec can't encode ...` при перенаправлении вывода в файл | Задайте кодировку: `set PYTHONIOENCODING=utf-8` (cmd) или `$env:PYTHONIOENCODING="utf-8"` (PowerShell) |
| Ступеньки на графике производных сплайна | Нормально: производные сплайна Эрмита непрерывны только в узлах. Уменьшаются параметром `beta` |
